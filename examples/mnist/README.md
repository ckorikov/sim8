# MNIST Digit Inference — sim8 Example

2-layer MLP digit classifier (0–9)

## Web Simulator

1. Open the web simulator (arch v3).
2. Load `mnist_inference.asm`.
3. Configure the pad: **Page** = `111`, **Offset** = `0`, **Size** = `28`
4. Draw a digit (0–9) on the pad canvas.
5. Run the program.
6. Read the result at console output.
